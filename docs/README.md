# Project Documentation

This folder contains the methodology and supporting documentation for the Third-Party Cyber Risk Assessment portfolio project.

## Included Deliverables

### 1. Assessment Methodology and Treatment Plan

**Files:**
- `Third_Party_Cyber_Risk_Assessment_Methodology_and_Treatment_Plan.pdf`
- `Third_Party_Cyber_Risk_Assessment_Methodology_and_Treatment_Plan.docx`

Describes the assessment approach, supplier due diligence process, risk scoring methodology, security control evaluation, framework alignment and risk treatment governance.

### 2. Risk Assessment Rationale

**File:**
- `Third_Party_Cyber_Risk_Assessment_Rationale_v2.docx`

Documents the rationale behind the six identified cyber risk scenarios, including:
- Inherent and residual risk scoring justification
- Control effectiveness assessment
- Supporting evidence considerations
- Risk treatment decisions
- Risk ownership and accountability
- ISO/IEC 27001:2022 and NIST CSF 2.0 alignment

## Framework References

The project uses the following reference frameworks:

- ISO/IEC 27001:2022
- NIST Cybersecurity Framework 2.0

## Assessment Reference Date

18 October 2026.

All assessment dates and results belong to a fictional point-in-time scenario and must be interpreted relative to this reference date.

## Disclaimer

All organisations, suppliers, scenarios, assessment results and supporting evidence are fictional and intended exclusively for educational and professional portfolio purposes.

This project does not represent an actual security audit, certification assessment or independent verification of real suppliers.
